## Peptide OmniPanel 1.3 / Engine v33.6 Release (2026-11-26)

**Peptide OmniPanel 1.3 (`v33.6`)** is a multi-endpoint ADMET, pharmacokinetics, safety, and antimicrobial prediction web platform spanning **47 harmonized experimental endpoints** (**25 Tier-1** Core ADMET/PK/Safety/Lipophilicity including macrocycle `LogD_decadiene` + **22 Tier-2** ESKAPE/Clinical MIC, MBC, MFC, Biofilm MBIC/MBEC & LC) across **51,007 unique peptides** (`82,414` curated observations; `4,535` censored/interval bounds), with explicit CI-aware evidence grading, applicability-domain gating, and transparent disclosure of negative results:
